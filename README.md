# AdminAI.az

Azərbaycandakı kiçik bizneslər üçün AI administrator. Randevu, müştəri və mesajları Azərbaycan dilində idarə edir.

Demo biznes: **Nərgiz Studio** (gözəllik salonu, Bakı).

## İşə salmaq

```bash
npm install
npm run dev
```

Brauzerdə [http://localhost:3000](http://localhost:3000) açın, sonra **Demo aç**.

Administratora yaza bilərsiniz:

- Bu gün nə var?
- Oxunmamış mesajlar
- Ayselə cavab yaz
- Randevunu təsdiqlə
- Kimdə borc var?
- Leyla kimdir?

Bu versiya lokal qaydalarla işləyir — API açarı tələb olunmur.
